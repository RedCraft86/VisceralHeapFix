Attempts to fix the Tendon features from the Visceral Heap biome in [Biomes O' Plenty](https://www.curseforge.com/minecraft/mc-mods/biomes-o-plenty) from spawning incorrectly (dotted) when using mods like [Incendium](https://www.curseforge.com/minecraft/mc-mods/incendium) or [Amplified Nether](https://www.curseforge.com/minecraft/mc-mods/amplified-nether) which increases the Nether's height.
This mod also exposes certain generation settings to make the features more configurable when it comes to spawn rates and look.
